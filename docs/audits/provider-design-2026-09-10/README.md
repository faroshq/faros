## Acceptance and phases

1. Inventory and audit every authored UI surface, verifying findings against current contracts. Record evidence, severity, impact, correction, and eventual verification.
2. Fix canonical shared defects, synchronize, and independently review.
3. Repair provider and host findings in non-overlapping packages; review each completed increment and repair regressions.
4. Run affected tests/typechecks/builds, design docs, PortalKit/AgentKit parity and conformance gates. Check rendered affected components/routes in light/dark at desktop/mobile sizes with keyboard and destructive-action paths.
5. Reconcile every defect and coverage gap for local user review; do not open a PR or push.

- App Studio: 34 Vue, 54 TypeScript, one CSS source; 68 tests inspected. Agents and Code: 73 authored frontend files plus their OAuth HTML producers. Infrastructure, Databricks, Edges, Kuery and Quickstart: 91 authored files. The host, shared kits and Dex/authentication output were reviewed separately. - Kuery and Quickstart have no additional confirmed source defects. The Kuery graph palette is a documented data-visualization exception with an explicitly incomplete assistive-technology review. Edges intentionally retains native select popup behavior. Agents' frozen toast adapter is a documented compatibility boundary. These are not silently reported as conformance failures or as fully verified accessibility.
- `providers/secrets` retains generated portal artifacts without authored implementation or an active provider manifest in this checkout. They were inventoried as retained distribution artifacts; changing minified generated code would not establish a maintainable source fix.
- Example application HTML, documentation embeds and visual-test harnesses are distinct from Faros console UI. Backend packages without presentation output were inventoried for UI producers rather than reclassified as frontend components.
- Source and fixture checks do not establish live provider connectivity, assistive-technology behavior, or a universal absence of design defects. Any additional confirmed defects found during repair review are added to the running inventory before correction.
